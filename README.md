# ESP32‑AI 

Это прошивка для ESP32 с экраном SSD1306: простой локальный клиент для общения с AI. Основной файл — `ai.ino`. Прошивка умеет подключаться к Wi‑Fi, отправлять запросы на AI‑сервис, показывать интерфейс на OLED, хранить чаты на SD и даже принимать простые патчи от AI.

Почему это удобно
- Лёгкий локальный чат прямо на устройстве — не нужно ПК.
- До 5 локальных чатов, история сохраняется на SD.
- Экранная клавиатура и управление кнопками.
- Можно расширять поведение через [PATCH]{...}[/PATCH] от AI (например: сменить заголовок, инвертировать экран, изменить IR‑пульсы).

Что уже реализовано 
- Подключение к Wi‑Fi и отправка запросов на AI (по умолчанию: https://text.pollinations.ai/openai/chat/completions).
- Быстрый веб‑поиск по Википедии и Fandom — результаты добавляются в контекст.
- Управление до 5 чатами, история → `/chats.json`, лог → `/ai_chat.txt` на SD.
- Интерфейс на OLED через U8g2, экранная клавиатура.
- Поддержка команд [PATCH]{"title":...}[/PATCH] — предлагается подтвердить перед применением; можно сохранить патч в `/patch.json`.

Главные настройки
- Wi‑Fi: ssid и password в начале `ai.ino`. Замените на свои
- AI endpoint и модель:
  - AI_URL = https://text.pollinations.ai/openai/chat/completions
  - AI_MODEL = "openai"

Аппаратные подключения
- Кнопки:
  - BTN_UP    = GPIO32
  - BTN_DOWN  = GPIO33
  - BTN_LEFT  = GPIO25
  - BTN_RIGHT = GPIO26
  - BTN_OK    = GPIO27
- SD (SPI):
  - SD_CS   = GPIO5
  - SD_SCK  = GPIO18
  - SD_MISO = GPIO19
  - SD_MOSI = GPIO23
- OLED (I2C):
  - SDA = GPIO21
  - SCL = GPIO22
  - Используется: U8G2_SSD1306_128X64_NONAME_F_HW_I2C
- IR-индикация:
  - IR_LED = GPIO4 (мигает при отправке запроса; параметр ir_pulses)

Зависимости (установите в Arduino IDE / PlatformIO)
- WiFi.h (ESP32 SDK)
- HTTPClient.h
- WiFiClientSecure.h
- ArduinoJson (v6 рекомендуется)
- U8g2lib
- Wire, SPI, SD

Как собрать и прошить 
1. Установите поддержку ESP32 в Arduino IDE (Tools → Boards → Boards Manager → esp32).
2. Откройте `ai.ino` или импортируйте проект в PlatformIO.
3. Проверьте и замените SSID/пароль и AI_URL.
4. Выберите плату и порт → Upload.

Коротко про использование
- Главное меню: Новый чат, Мои чаты, Настройки.
- Навигация: UP/DOWN/LEFT/RIGHT, OK — выбор/ввод.
- В чате: нажмите OK → экранная клавиатура.
- История и логи сохраняются на SD-карте.

Patch‑механизм
- AI может вернуть блок вида:
  [PATCH]{"title":"Имя","invert":true,"ir_pulses":3,"banner":"Текст"}[/PATCH]
- Прошивка распознаёт, покажет содержимое и предложит подтвердить применение. После подтверждения патч применяется в рантайме и может быть записан в `/patch.json`.

# ESP32-AI

Проект: прошивка для ESP32 — интерфейсный клиент для общения с ИИ (файл `ai.ino`).

Описание
--------

`ai.ino` — это полноценная прошивка для ESP32, реализующая простой локальный чат с ИИ на устройстве с экраном SSD1306, SD-картой, кнопками и ИК-индикацией. Прошивка умеет:

- Подключаться к Wi‑Fi и отправлять запросы к внешнему AI-сервису (по умолчанию: https://text.pollinations.ai/openai/chat/completions).
- Выполнять поиск по Википедии и Fandom и добавлять найденную информацию в контекст запроса.
- Вести до 5 локальных чатов, сохранять историю на SD-карту (`/chats.json`) и лог запросов (`/ai_chat.txt`).
- Отображать интерфейс на OLED (SSD1306) через библиотеку U8g2, имеет экранную клавиатуру и кнопочное управление.
- Принимать от AI команды в формате `[PATCH]{...}[/PATCH]` и применять настройки (например: `title`, `invert`, `ir_pulses`, `banner`).

Файл с прошивкой
-----------------
Путь: `ai.ino` (в корне репозитория). Откройте и проверьте настройки перед прошивкой.

Важно: убраны явные значения пароля/SSID из описания README — не храните секреты в открытом виде в репозитории.

Настройки и безопасное хранение секретов
---------------------------------------
Прошивка содержит настройки подключения к Wi‑Fi и AI-провайдеру в коде. Чтобы не выкладывать реальные пароли в репозиторий, следуйте этому простому рабочему процессу:

1. Скопируйте файл `config.example.h` в `config.h` и заполните свои значения (SSID, пароль, AI_URL и т.д.).
2. Убедитесь, что `config.h` добавлен в `.gitignore` (в корне репозитория уже есть правило для `config.h`).
3. В `ai.ino` включите `config.h` (если вы этого ещё не сделали):

   #include "config.h"

   и используйте константы оттуда или замените строки `ssid`/`password` значениями из `config.h`.

Пример `config.example.h` — служит шаблоном и не содержит реальных паролей.

Аппаратные подключения (пины)
----------------------------
- Кнопки:
  - BTN_UP    = GPIO32
  - BTN_DOWN  = GPIO33
  - BTN_LEFT  = GPIO25
  - BTN_RIGHT = GPIO26
  - BTN_OK    = GPIO27

- SD-карта (SPI):
  - SD_CS   = GPIO5
  - SD_SCK  = GPIO18
  - SD_MISO = GPIO19
  - SD_MOSI = GPIO23

- OLED (I2C):
  - SDA = GPIO21
  - SCL = GPIO22
  Используется библиотека U8g2 (U8G2_SSD1306_128X64_NONAME_F_HW_I2C).

- IR-индикация:
  - IR_LED = GPIO4 (мигание при отправке запроса и настройка `ir_pulses`).

Зависимости (библиотеки)
------------------------
Убедитесь, что в Arduino IDE или PlatformIO установлены:
- WiFi.h (входит в ESP32 SDK)
- HTTPClient.h
- WiFiClientSecure.h
- ArduinoJson (рекомендуется v6)
- U8g2lib
- Wire, SPI, SD

Сборка и прошивка (Arduino IDE)
-------------------------------
1. Установите поддержку ESP32 в Arduino IDE (Tools → Boards → Boards Manager → esp32).
2. Откройте `ai.ino` (File → Open) или импортируйте проект в PlatformIO.
3. Создайте `config.h` на основе `config.example.h` и заполните значения.
4. Выберите плату и порт, затем нажмите Upload.

Использование (кратко)
---------------------
- Главное меню: + Новый чат, Мои чаты, Настройки.
- Навигация кнопками: UP/DOWN/LEFT/RIGHT, OK для выбора/ввода.
- В режиме чата: нажмите OK → откроется экранная клавиатура.
- Паузы и статусы показываются на OLED. История и логи сохраняются на SD.

Механизм обновлений через AI (`[PATCH]`)
-------------------------------------
AI может вернуть в ответе блок в формате:

[PATCH]{"title":"Имя","invert":true,"ir_pulses":3,"banner":"Текст"}[/PATCH]

Прошивка распознаёт такой блок, предлагает подтвердить применение (OTA-подобно):
- При подтверждении патч применяется в рантайме и (опционально) сохраняется в `/patch.json` на SD.

Безопасность и примечания
-------------------------
- Не храните реальные пароли/ключи в публичных репозиториях.
- Текущее подключение HTTPS в прошивке выполняется в небезопасном режиме (`client.setInsecure()`). Для продакшена рекомендуется реализовать проверку сертификатов.
- Проверьте размеры и ограничения по памяти при добавлении больших строк в историю/логи.
